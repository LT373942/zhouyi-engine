# 盲法交叉验证协议（Blind Modeling Protocol）

## 目的

消解"研究者自由度"质疑：原三案例由本团队建模，属性判定与实体编码含主观成分，
存在"自己出题自己判卷"的循环风险。本协议引入**独立建模者**（隔离上下文的大语言
模型会话），在只获得"维度定义 + 事发前公开事实 + 实体池"的条件下独立完成实体编码，
并与本团队编码比对。

## 诚实边界（重要）

独立建模者是大语言模型，其训练数据含相关历史事件的公开记录，"预测"不可能完全
不知晓结局。因此本协议验证的**不是预测能力**，而是：

1. **编码可复现性**（inter-rater reliability）：独立建模者基于事发前事实独立编码，
   与本团队编码的一致率。一致率高 ⇒ 编码由事实决定，而非由结局倒推；
2. **结构-断裂收敛性**：盲模关系网上的同构群标记与公开断裂集的重合度。

训练知识污染无法消除，只能声明。本协议的全部材料随仓库公开，任何人可复现。

## 共享输入（发给独立建模者）

- 六维维度定义（各维度阳/阴取值语义）——方法论的一部分，必须与本团队一致；
- 实体池：案例涉及的实体名单及一句话中性描述（案例范围界定，声明为共享输入）；
- 事发前公开事实表：每个实体的事发前可查证事实，不含任何结局信息；
- 输出格式规范（JSON schema）。

## 禁止输入（独立建模者不可获得）

- 本团队的实体编码（cases/*.json 的 values 字段）；
- 本团队的依赖图、事件种子、断裂集；
- 本团队的回测结果（results/）；
- 网络搜索（避免检索到本仓库公开页与事后报道）。

## 任务（独立建模者执行）

1. 逐实体依据事发前事实表判定六维属性（yang/yin/none），不确定的维度显式留 none；
2. 依据事实表声明依赖边（h 依赖 t）与事件种子；
3. 基于**结构推理**（同构共振 + 依赖传导），而非历史回忆，给出预测断裂名单；
4. 输出 JSON 至 protocol/blind/<case>_blind.json。

## 比对指标（tools/blind_compare.py 计算）

- 编码一致率：六爻完全一致的实体比例；逐维度一致率；
- Cohen's kappa（按爻位二值池化）；
- 盲模同构群（≥3）与公开断裂集的 M1/M2（复用回测代码）；
- 本团队 flagged 与盲模 flagged 的重叠率。

## 已知局限

- 实体池由本团队界定（范围自由度仍在，已声明）；
- 独立建模者与本团队使用同类大语言模型，存在同源偏差；
- 事实表由本团队编写（措辞自由度，已尽量中性化并逐条注明事前可查证）。
